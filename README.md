# Khám phá Lộc Ninh 3D

A free 3D tourism exploration game for Lộc Ninh town, Bình Phước, Vietnam.
No API key, no cost — built with CesiumJS, Esri satellite imagery and OpenStreetMap.

## Play

- Explore the 3D globe and fly to 7 pinned places around Lộc Ninh.
- Check in at all 7 places to collect stamps.
- Take the 3-question quiz and test your knowledge.
- Get directions to each place.

## The 7 places

1. Trung tâm Lộc Ninh (QL13 roundabout)
2. Nhà Giao Tế
3. Chợ Lộc Ninh
4. Căn cứ Tà Thiết
5. Chùa Sóc Lớn
6. Rừng cao su
7. Cửa khẩu Hoa Lư

## Run it

Just open `index.html` in a browser. Or deploy it as a static site on
Vercel / GitHub Pages — no build step needed.

## Tech

- CesiumJS 3D globe
- Esri World Imagery + OpenStreetMap
- Plain HTML/CSS/JavaScript, no backend
